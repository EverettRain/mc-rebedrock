点击网格上某个 UV 框后：改“归属面”即重贴该框给另一个几何面（例如把 B Body 改成 F Body——身体的正面改采样原背面矩形）；勾选“旋转 180°”让该框倒置采样。此扩展会写入 geo.json 的 cube.faces，当前预览生效。

在中网格子上拖动某个面，会整体平移该 cube 的 box-UV 网（改的是该 cube 的 uv 起点，与游戏 boxUvFaceRect 一致）。←→↑↓ 微调 1 texel，Shift 为 4。 uv 不会被夹到贴图范围内：实体采样器是 REPEAT，越界的网会绕回另一侧，预览与游戏一样照实呈现（网格里以虚线标出）。
